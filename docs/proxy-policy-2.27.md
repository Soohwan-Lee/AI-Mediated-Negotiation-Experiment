# Proxy wording and supplementary arguments

2026-09-10. Minor policy alignment with Experimental Design Ver.2.27, sections 6.5–6.7 and 8.7. This document supersedes older descriptions of fixed task-by-role pairs or factual omissions. It does not change the experimental structure.

- Both policies use identical, fixed, work-focused phrasing in `PROXY_REASON_BASES`. Original reason cards and Direct wording stay unchanged. Facts about who acted, private delivery, and non-disclosure are preserved.
- Each task and role has three arguments in `PROXY_WORK_BENEFITS`: WR1 and WR2 address both work arrangements; SB1 supports the focal request explained by authorized SB. WR-only uses WR1 + WR2. Authorized SB uses WR1 + SB1.
- Each Proxy adds exactly two arguments once, introduced by `Additional work considerations from this Proxy:`. The participant Proxy uses its first reason turn. The counterpart uses opening on WR-only, or reciprocal SB disclosure on the SB path. No additional turn or later refusal argument is added.
- The server-controlled renderer selects the pair from the designated card layer. The LLM cannot choose a different pair or rewrite the factual base. Added arguments do not count as SB or change the score.
- Participant instructions explain reformulation and information-dependent supplementation without promising greater persuasion or a better outcome. The leave illustration is separate from the neutral practice.

Unchanged: conditions, assignments, original cards, task points, reciprocal SB gate, seven-turn protocol, direct confirmation, measures, timers, payment, and storage. This local update does not deploy the application or authorize recruitment.
